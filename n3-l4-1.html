Variables, términos y coeficientes

›

Una variable es una letra que representa un número desconocido. Una expresión algebraica combina variables, números y operaciones. Cada parte separada por + o − es un término; el número que multiplica a la variable es su coeficiente, y el término sin variable es la constante.

Anatomía de una expresión

Cada término aparece desarmado en sus partes. Fíjate en los signos: el signo que va delante pertenece al término.

Coeficiente invisible: cuando una variable aparece sola, como x, su coeficiente es 1 (x = 1x). De igual modo, −x significa −1x. Recordarlo evita errores al combinar términos.

Combinar términos semejantes

›

Dos términos son semejantes si tienen la misma variable elevada al mismo exponente. Cada tipo de término forma una «familia», y solo se combinan los de la misma familia, sumando o restando sus coeficientes. Las constantes forman su propia familia.

La propiedad distributiva

›

Cuando un número multiplica a una suma o a una resta entre paréntesis, multiplica a cada término de adentro, no solo al primero.

a(b + c) = a · b + a · c

Por qué funciona: el modelo de área

Un rectángulo de altura a y base (x + c) se puede partir en dos. El área total es la misma, se calcule como se calcule.

Con signos: el signo del factor también se reparte. −2(x − 5) = −2x + 10, porque (−2)(−5) = +10. El error más frecuente es multiplicar solo el primer término: 3(x + 4) no es 3x + 4.

Evaluar expresiones

›

Evaluar es sustituir la variable por un valor y calcular, respetando el orden de las operaciones: paréntesis, exponentes, multiplicación y división, suma y resta.

Sustitución paso a paso

Usa paréntesis al sustituir: escribir 2(3) en lugar de 23 evita confundir la multiplicación con un número de dos cifras. Con negativos es imprescindible: si x = −3, entonces x2 = (−3)2 = 9, pero −x2 = −(−3)2 = −9.
