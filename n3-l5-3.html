La estrategia de cuatro pasos

›

Despejar una variable es reescribir la fórmula para que esa letra quede sola de un lado. La clave: las demás letras se tratan como si fueran números. Por eso despejar una fórmula es lo mismo que resolver una ecuación que ya sabes resolver.

1Identificar qué variable se quiere despejar.
2Aislarla con operaciones inversas, tratando las demás letras como números.
3Simplificar el resultado, con fracción si hace falta.
4Verificar que la variable buscada quedó sola de un lado.

Con números y con letras, en paralelo

A la izquierda, una ecuación con números; a la derecha, la fórmula. Los pasos son los mismos.

Fórmulas comunes

›

Estas fórmulas aparecen mucho en el examen. En cada una se puede despejar cualquiera de sus letras.

Fórmulas de uso frecuente
ContextoFórmulaSignificado de las letras
Distanciad = rtd: distancia, r: rapidez, t: tiempo
Área de un rectánguloA = bhb: base, h: altura
Volumen de una cajaV = lwhl: largo, w: ancho, h: altura
Interés simpleI = PrtP: capital, r: tasa, t: tiempo en años
Perímetro de un triánguloP = a + b + ca, b, c: los tres lados
FuerzaF = mam: masa, a: aceleración
Si la letra está multiplicada por otras, se divide entre todas ellas: en I = Prt, P = I/(rt). Si está sumada, se restan las demás: en P = a + b + c, c = P − a − b.

3

Fórmulas de dos pasos

›

Algunas fórmulas necesitan más de una operación. Se deshacen en orden inverso, igual que las ecuaciones de dos pasos: primero se quita lo que está sumado o restado, y al final lo que multiplica.

Paso a paso

El paréntesis importa: C = (5/9)(F − 32) no es lo mismo que C = (5/9)F − 32. Primero se resta 32 a toda la F y después se multiplica el resultado completo.

Aplicar la fórmula despejada

›

Hay dos caminos para calcular una letra: despejar primero y sustituir después, o sustituir primero y resolver la ecuación que queda. Los dos dan el mismo resultado. Despejar primero conviene cuando hay que calcular muchas veces, porque la fórmula despejada sirve para todos los casos.

Dos caminos, el mismo resultado

Practica: calcula con la fórmula

Escribe solo el número, sin unidades. Puede ser decimal o fracción.
