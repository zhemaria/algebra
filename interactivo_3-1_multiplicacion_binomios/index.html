Módulo 3 · Identidad: el cuadrado de un binomio

(a + b)² = a² + 2ab + b²  ·  (a − b)² = a² − 2ab + b². Completa las tres piezas: el cuadrado del primero, el doble del producto y el cuadrado del segundo.

El error más frecuente: escribir (x + 5)² como x² + 25. Falta el término del medio, 2ab. Elevar al cuadrado un binomio nunca es elevar al cuadrado cada término por separado.
